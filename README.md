# 🚖 Uber Data Analytics Dashboard (Power BI)

## 📌 Project Overview
This project analyzes Uber ride booking data to uncover operational inefficiencies, cancellation patterns, revenue insights, and demand trends.

## 🧹 Data Cleaning
- Null handling
- Business logic validation
- Feature engineering
- Star schema modeling
- Surrogate key implementation

## 📊 KPIs Designed
- Total Bookings
- Completion Rate
- Cancellation Rate
- Revenue
- Pickup vs Drop analysis

## 🏗 Data Model
- Fact_Rides
- Dim_Date
- Dim_Vehicle
- Dim_Location
- Dim_Payment

## ⚙ Tools Used
- Power BI
- Power Query
- DAX
- Git
